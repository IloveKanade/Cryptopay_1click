# 🚀 支付系统快速入门指南

## 📋 系统简介
这是一个基于中间人钱包的USDT支付系统，用户创建支付链接后，系统会随机选择一个中间人钱包接收支付，然后自动转账到用户指定的钱包地址。

## ⚡ 快速启动

### 1. 启动系统
```bash
# Windows
start-all.bat

# Linux/Mac
./start-all.sh
```

### 2. 访问系统
- **前端**: http://localhost:3000
- **管理后台**: http://localhost:3000/admin

## 🎯 核心功能

### 用户端
1. **注册/登录** → 创建账户
2. **创建支付链接** → 设置金额和回调地址
3. **分享链接** → 用户完成支付
4. **查看订单** → 监控支付状态

### 管理员端
1. **中间人钱包管理** → 添加钱包和私钥
2. **费率配置** → 设置手续费率
3. **转账记录** → 查看所有转账
4. **系统设置** → 配置Epusdt和回调

## 💰 支付流程

```
用户创建支付链接 → 系统随机选择中间人钱包 → 用户支付USDT → 
系统扣除手续费 → 自动转账到用户钱包 → 发送回调通知
```

## ⚙️ 手续费计算
- **固定手续费**: 支付金额 × 1%
- **网络手续费**: 动态获取（约0.001-0.01 USDT）
- **总手续费**: 固定手续费 + 网络手续费

## 🔧 配置说明

### 必需配置
1. **中间人钱包**: 添加至少一个TRC20钱包
2. **Epusdt服务**: 配置Epusdt基础URL
3. **回调地址**: 设置全局回调地址（可选）

### 重要提醒
- 确保中间人钱包有足够的TRX和USDT余额
- 私钥请妥善保管，不要泄露
- 建议在测试网络先测试功能

## ❓ 常见问题

**Q: 转账记录页面白屏？**
A: 已修复，刷新页面即可。

**Q: 如何添加中间人钱包？**
A: 管理员登录 → 中间人钱包管理 → 添加钱包 → 输入地址和私钥。

**Q: 支付失败怎么办？**
A: 检查钱包余额、私钥正确性、网络连接。
